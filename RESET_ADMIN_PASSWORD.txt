Use this whenever you want to reset or change the admin login password.

- Login URL: http://localhost:5000/login.html

HOW TO RESET THE ADMIN PASSWORD AT ANY TIME:
1. Double-click RESET_ADMIN_PASSWORD.bat (or run `node scripts\reset-admin-password.js`).
2. Press Enter to keep the default admin email, or type another email.
3. Enter your new password (minimum 8 characters) and confirm it.
4. The utility automatically updates SQLite and synchronizes ADMIN_PASSWORD in your .env file.
5. You can now immediately log in at http://localhost:5000/login.html.
