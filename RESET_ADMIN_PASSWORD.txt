LAXMINARAYAN GROUP — ONE-TIME ADMIN PASSWORD RESET

Use this only when the admin password stored in the SQLite database is unknown or no longer matches .env.

IMPORTANT:
- Stop the running Node server first (Ctrl+C).
- Open this exact project folder.
- Make sure npm install has already completed.
- Double-click RESET_ADMIN_PASSWORD.bat.
- Enter the admin email shown in .env, then enter a NEW password twice.
- The password is not written to this file and is stored in the database only as a bcrypt hash.
- Existing admin sessions are invalidated after a successful reset.
- The utility creates .admin-password-reset-used after success and refuses to run again unless that marker is intentionally removed.
- Do not upload .env, .admin-password-reset-used, or ADMIN_CREDENTIALS.txt to public hosting.

After the reset:
1. Start the server with START_BACKEND.bat or: npm start
2. Open http://localhost:5000/login.html
3. Use the admin email and the NEW password you just chose.
4. For another computer on the same Wi-Fi, use http://YOUR-PC-IP:5000/login.html.
