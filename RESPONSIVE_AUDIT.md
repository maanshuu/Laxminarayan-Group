# Responsive audit

Updated from the user's current working master ZIP.

## Views covered
- Main website: desktop / tablet / mobile
- Project category pages: desktop / tablet / mobile
- Customer dashboard: desktop / tablet / mobile
- Admin dashboard: desktop / tablet / mobile
- Login: desktop / tablet / mobile
- Signup: desktop / tablet / mobile

## Main fixes
- Mobile navigation collapses into a hamburger menu on the main site and project-category pages.
- Header links no longer run off-screen.
- Main content grids collapse cleanly on narrow screens.
- Admin forms become one-column on phones.
- Admin tables remain usable via horizontal scrolling rather than overflowing the viewport.
- Project media grids adapt to tablet and phone widths.
- Customer dashboard cards and tables adapt to small screens.
- Login/signup forms fit narrow devices without horizontal overflow.
- Existing authentication, API routes, database structure and JavaScript behavior were not intentionally changed.
